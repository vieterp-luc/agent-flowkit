## 1. Anatomy của thumbnail mẫu (Em Bé Thông Minh)

Bóc thumbnail đã thành công thành 4 vùng theo framework:

```
┌─────────────────────────────────────────────────────────────┐
│ [LOGO]              ┌────────────────┐    [REACTION]        │
│ Cổ Tích             │                │   👑 Vua + 3 quan    │
│ GEN Z               │     HERO       │   sốc miệng há hốc   │
│                     │   Em Bé        │                      │
│ [TITLE 3D]          │   ngón tay     ├──────────────────────┤
│ EM BÉ               │   chỉ thiên    │   [MINI SCENE]       │
│ THÔNG MINH          │   golden glow  │   🐃 Trâu cày        │
│                     │   halo + rim   │   + bé chăn hỏi ?    │
│                     │   light vàng   │                      │
│ [MINI SCENE]        │                │                      │
│ 🏯 sứ giả + ngựa    │   [MYSTERY]    │   [MINI SCENE]       │
│ + 4 mâm cỗ          │   ốc xoắn      │   ốc xoắn + kiến     │
│                     │   bí ẩn        │   kéo chỉ            │
├─────────────────────┤                ├──────────────────────┤
│ [MINI SCENE]        │   [PROOF]      │   [REACTION 2]       │
│ 👦 bé soi kim       │   triều đình   │   3 sứ thần ngoại    │
│                     │   cờ xí        │   há mồm bất ngờ     │
│                     │                │                      │
│         [TITLE RIBBON đỏ] TRẠNG NGUYÊN TRẺ NHẤT             │
└─────────────────────────────────────────────────────────────┘
```

**Vì sao work:**
- Mắt nhân vật chính + ngón tay chỉ thiên = focal point lập tức
- Mọi nhân vật phụ đều có biểu cảm SỐC/HÁ MỒM → kích thích "chuyện gì xảy ra?"
- Có ốc xoắn (mystery) + triều đình (proof) + 4 mini scene → kể trọn vẹn câu chuyện
- Background tím tối + subject vàng sáng → tương phản cực mạnh, lúc thu nhỏ vẫn nổi

## 2. Cấu trúc 4 vùng (framework chính)

### Hero (60% diện tích)
**MỘT** nhân vật chính, KHÔNG bao giờ 2.

- Đặt trung tâm, chiếm 40-60% frame
- **Mắt to expressive** (đặc trưng Pixar)
- Biểu cảm mạnh: tự tin / ngạc nhiên / quyết tâm / smug grin
- **Rim light vàng** + **halo glow** quanh đầu
- Nhìn thẳng vào camera (KHÔNG nhìn ngang)
- Vai/ngực trở lên (medium close-up), KHÔNG full body

### Reaction (20%)
1-2 nhân vật phụ phản ứng cực mạnh → tạo hiệu ứng "wow"
- Vị trí: thường góc phải trên hoặc xung quanh hero
- Biểu cảm: 😱 sốc / 😲 kinh ngạc / 🤯 không tin nổi
- TRÁNH: cười nhẹ, mặt bình thường, biểu cảm trung tính

### Mystery (10%)
1 vật/yếu tố gây tò mò — câu trả lời cho "tại sao click?"
- Ốc xoắn / kiếm thần / bức thư / kho báu / cánh cổng / bản đồ / dấu hỏi phát sáng
- Có glow nhẹ để đánh dấu là "thứ đặc biệt"

### Proof (10%)
Bằng chứng câu chuyện là **thật** — tăng credibility
- Triều đình / ngai vàng / lâu đài / chiến trường / ngôi làng cổ
- Đặt ở background hoặc mini scene

## 4. Workflow chính: AI all-in-one (1 command)

> **Cập nhật 2026-06-01:** Imagen 4 render được cả VN diacritic + logo neon + title 3D trong cùng 1 ảnh — KHÔNG cần Canva post-process. Pipeline đã có script reusable.

```bash
python scripts/vanvo_thumbnail_gen.py <slug>
# vd: python scripts/vanvo_thumbnail_gen.py coc-kien-troi
# → output/van_vo/<slug>/ep01/thumbnail_branded.png
```

Script tự load: book data (entities, title, optional `thumbnail` config) + project ID + character ref media_ids từ `_project.json` (đảm bảo hero giống nhân vật trong video) → compose framework 4-vùng + text instructions → POST `/api/flow/generate-image` → save PNG.

### Optional `thumbnail` block per book (recommended)

Thêm vào book dict trong `vanvo_books_data.py` để control kết quả — Cóc Kiện Trời là mẫu:

```python
"thumbnail": {
    "pose": "<hero pose + key gesture>",
    "mystery": "<mystery object glowing in foreground>",
    "proof": "<setting that proves story is real>",
    "mini_scenes": "1) <scene a>, 2) <scene b>, 3) <scene c>, 4) <scene d>",
    "subtitle": "<optional ribbon sub-title>",  # bỏ field nếu không muốn ribbon
}
```

KHÔNG có block này → script auto-derive từ `caption_bullets` (chất lượng thấp hơn, có warning).

Title auto = `book["title"].upper()`. Override per-run: `--title "..."`.

### Cách Imagen render VN diacritic chuẩn (đã verify)

Imagen 4 render đúng "Cổ Tích / CÓC KIỆN / TRỜI" khi prompt có:
- `text reads exactly "X"` (quoted explicit)
- Closing line `all text in correct Vietnamese spelling`
- Avoid abbreviations / phonetic spelling

Script đã bake các phrase này — KHÔNG bỏ.

## 5. Workflow per episode (3 bước)

1. **Render video trước** (tạo project + entity refs cần cho character consistency):
   ```bash
   python scripts/vanvo_render_pipeline.py <slug>
   ```
2. **(Optional) Thêm `thumbnail` block** vào book trong `vanvo_books_data.py` — nếu muốn customize. Không có cũng chạy được nhưng default thấp hơn (script emit warning).
3. **Gen thumbnail:**
   ```bash
   python scripts/vanvo_thumbnail_gen.py <slug> [--title "OVERRIDE"]
   ```
   Output: `output/van_vo/<slug>/ep01/thumbnail_branded.png` 1920×1080 sẵn upload YouTube.

## 5b. Fallback: ffmpeg drawtext composite (khi AI text fail)

Imagen render text VN sai (rare — vd title >5 từ hoặc diacritic phức tạp). Fallback flow:

1. Gen base no-text (sửa prompt thêm "NO TEXT, NO logos") → `thumbnail_v2.png`
2. ffmpeg composite logo + title 3D — font BẮT BUỘC `/Library/Fonts/Arial Unicode.ttf` (Arial Black/Bold thiếu glyph Ệ Ờ). 3-layer drawtext cho 3D extrude: đen base → nâu offset → vàng main + borderw 8-10px + shadow. Tham khảo session 2026-06-01 hoặc `build_thumbnail()` trong `vanvo_render_pipeline.py`.

## 7. Lỗi thường gặp — tránh

| Lỗi | Hậu quả | Fix |
|-----|---------|-----|
| 2-3 hero ngang nhau | Mắt không biết focus → CTR giảm | Chỉ 1 hero, các nhân vật khác làm reaction |
| Mặt hero bình thường / cười nhẹ | Không tạo "tò mò" | Bắt buộc biểu cảm mạnh: sốc/quyết tâm/tự tin smug |
| Palette pastel/xám | Không nổi khi thu nhỏ | Stick warm amber + gold + tím deep |
| Ánh sáng phẳng đều | Mất chiều sâu | Bắt buộc rim light + god rays + halo |
| Title > 4 từ | Đọc không kịp | Cắt còn ≤4 từ chính, ribbon phụ cho hook dài |
| Quá nhiều mini scenes (>4) | Clutter | Tối đa 4, mỗi cái dễ hiểu trong 1 giây |
| Logo bị che / chữ trồi vào hero | Mất thông tin | Logo top-left, title góc trái, hero trung tâm — KHÔNG đè |
